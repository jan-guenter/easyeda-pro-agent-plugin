# Native empty reference result codec and ledger

A new unmounted inverse-only emitter implements the four fixed result ledgers
in original PCB, SCH, derived-footprint and device order. Each bind requires the
separately maintained original sender-source hook and exact retained starting
breakpoint. No selector or caller boolean can provide that hook. The SCH hook
must retain its distinct method/handler/outer-RPC continuation; worker hooks
must join the actual completed native send and original worker query.

The native ledger owns three result breakpoints per query, all observed holds,
once-only removals/resumes and their acknowledgements. Worker order is local,
WHOHAS, PUBLISH, reply, outer callback and next RPC or final yw. SCH starts at
its already-held outer return, then observes reply, callback and next RPC.
The final next/yw point remains held. A fixed native next-progress sender must
consume the original next hold before its next resume; there is no pipe consume
verb. Finishing all four results grants no l, DEL, clock, Save or SQL authority.

All helper counts and complete role rosters are exact. The two ordinary worker
results require69 calls and10 frame projections; device requires71 and10.
SCH requires44 and5. These total288 distinct helper source receipts. Metadata
reads retain the separately derived1158-CDP and1225-control maxima. Every
attempt reserves before dispatch; a new-ledger exception permanently poisons
that ledger and cannot revive a lost acknowledgement.

The two immutable tables jointly store unique programs across all four kinds.
Byte-identical old GET programs use their existing immutable catalogue; old
programs, ledgers and budgets are unchanged. All180 per-message SHA-256 goldens
remain in the packed tables and are checked by the actual C# smoke. An attempted
fixed prefix/suffix program delta saved less compressed data than its decoder
added, so that experiment was discarded.

The emitted new C# fragment measures30,635 bytes. The complete current inverse
layout has not been admitted with this fragment. Its unchanged2MiB compiler
limit may require further lossless storage work after the sender/progress union
is composed. No oversized helper or tracked artifact was emitted.

A bounded49KB test assembly used the actual shared table/JSON/program decoders
and the unchanged new fragment under C# LangVersion5. All180 exact wire hashes,
unknown-kind denial and unissued bind/next/final refusals passed. Its original
owner/source/send boundaries deliberately throw and issue no native receipt.
A focused storage test independently expanded every program/template/hash;
both TypeScript configurations and strict changed-file lint passed. The first
private harness compile lacked surrounding using declarations and selected the
wrong existing decoder overload; correcting that harness changed no production
code. Core/controller/pipe/profile/generator mounting and full union compilation
remain with the coordinating agent. No live application call was made.
