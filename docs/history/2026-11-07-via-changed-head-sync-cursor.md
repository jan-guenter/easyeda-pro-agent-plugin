# Via changed-head sync cursor

The private changed-head cursor follows the original second `syncCloud()` call
from `uploadCloud`'s `finally`. The earlier call while `isUploadingCloud` is true
belongs to the uploader's separate deferred-call collector. The existing initial
and periodic same-head cursors retain their exact contracts.

`current-pcb-via-prospective-sync-data.ts` derives the complete branch candidate
from the original initial branch and completed history effects. Its optional
opaque Node issuer also checks the actual owner, plan, completed initial reader,
body and effects references. It does not require future history rows, invent
append timestamps, or grant a request. Core can use the acyclic pure comparison
under its own original registries.

The new cursor admits seven original source roles in order: entry, full, branch
response, histories response, merged, finalizing and returned. The actual branch
reply is checked before its head property is read. At the histories response the
host must late-bind the genuine live cache projection, which includes the actual
request-owned SQLite `yB` rows. Full row fields and order are checked before
`hd`/`du`. Mutable and appended heads have separate exact merge predicates.

The entry retains the original initial capture and source module, checks the
group array's Inspector metadata before traversal, and qualifies twelve original
loader callees by actual script, function shape, location and complete source.
The fixed source roster includes `getLastHistoryUuid`, `getFlowParse` and
`applySnap`; the latter cannot reach its snapshot API under this one/two-head
profile. A real Node Inspector regression compiles only inert definitions and
checks the function locations and original cloud-finally call position.

Every response object is first classified by correlated Inspector metadata.
The fixed programs compare retained JavaScript references before traversing
their fields. Independently wrapped Inspector object IDs are never compared as
JavaScript identity. The complete resulting history index is read as a bounded
Inspector graph and must equal the genuine expected full index bytes. A Proxy,
accessor, changed row, changed pointer, extra field or order drift refuses while
the original pause remains held.

The pre-`du` replay command is a selector with no receiver, argument, expression
or program input. Its future native mount must substitute the same owner's
retained Save Array6, entry Array13 and exact held merged frame, using the fixed
readonly replay program. It must not treat the selector as a public grant.
