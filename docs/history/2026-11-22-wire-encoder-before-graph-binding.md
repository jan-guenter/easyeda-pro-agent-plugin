# Wire encoder before-graph binding

V5 Core prepares one encoder cursor from the issued Wire plan after the
original SDK holder's preflight. It binds the selected renderer pipe,
the retained globals reflection tuple and the exact
[original schematic source receipt](2026-11-22-wire-encoder-original-source-receipt.md).
The cursor rechecks those identities before each operation, rejects a
different transport, retains its original attempt and requires observed
termination of the original generation before retirement.

The fixed read-only binder follows the holder to its before tree, the
handler's live source map and the real model index. It compares the before
snapshot against that mapping without substituting the snapshot for the
handler's pointer. Its 19-entry return contains the graph and the six
row, prototype and upload-function groups in original source-map order.
The cursor requires the binder's generated-script proof, reads that tuple
and requalifies the codebook's own source-first reply before handing the
fixed metadata and membership sequence to the existing peer reader.
The membership helper also requires its original generated-script proof.

The isolated Inspector regression accepted the binder with
`throwOnSideEffect:true`. It verified the original map identity and peer
order, refused later mutation state and a substituted snapshot, and
confirmed that an unissued copied plan caused zero dispatches.
The existing V5 helper and dispatcher still lack an encoder lane. Live use
requires exact graph and peer action routing, bounded polling and
original helper event/source custody. Geometry's earlier startup
`_init` and watch registration remain separate.
