# Saved schematic scene native codec and replies

The saved schematic scene has a separate finite native encoder for capture,
observe and object-group release. Its fixed packed readonly program, flags,
selectors, argument lengths, field rosters and physical65,536-byte bound are
independently checked. Save, Modify and navigation have no encoding.

Actual Linux C#5 compilation of the full current schematic compiler plus the
new partial-class codec passed. All three emitted messages match independently
constructed JavaScript wire hashes. The added fragment is14,343bytes; the
complete private compiler input with its smoke entry is1,895,689bytes. This
build-only smoke creates no Windows process, Job or application. Native
enrollment and dispatch remain separate from this codebook.

The new reply decoder accepts an exact retained Array(2) capture, complete
seven-record readonly scene and genuine empty release response. It checks the
original window identity and preserves every false native-origin, cold-load,
persistence, reopened and execution flag. Exceptional, accessor-bearing,
contradictory or fabricated release packets refuse.

Two focused tests passed using the actual Node24 Inspector on the existing
inert scene graph. They preserve all peer/source checks and observe zero
setters, transactions and Save calls. Strict type-aware lint passed. The test
has one narrow exception for Node's void declaration on a command whose actual
empty runtime envelope is checked independently. No guard or global lint rule
was relaxed. The original cold/page/source context and final saved/reopened
proof remain necessary before runtime acceptance.
