## Next implementation batches

1. **Managed local fixture import and registration.** Qualify one native project
   archive, exclusive managed destination, exact registration identity, complete
   document roster and original closure. The installed importer has a real
   local-path branch, but its extraction, job, registration and partial-failure
   effects still need qualification. A checkpoint copy does not register a new
   project or provide the required Via-only geometry. Generic project creation
   involves account/workspace state; project copy is an installed stub.
2. **Ordinary PCB observation owner.** Reuse the current 209 layer, object,
   selection and shape readers through a separate ordinary-project lifecycle.
   Current diagnostic opening requires disposable attestation. Preserve each
   reader's existing geometry and membership limits and prove original cleanup;
   broader read eligibility supplies no writer or Save authority.
3. **Passive schematic-page opening and reads.** Add an exact type-1 page owner,
   immutable source and existing Text/Wire/Bus DTO readers. Current schematic
   container-title editing and symbol pin reading do not establish page-canvas
   or placed-component pin support. Resolve selected objects only for a complete
   supported DTO roster, refusing unknown families.
4. **Operation-owned structure/Save completion and one PCB writer.** Start with
   an existing unlocked Via coordinate change, or one Via addition on a supplied
   empty disposable PCB. Prove the original operation's delayed structure work,
   complete closed SQL effect, consumed Save and cache-excluded reopen. Enable
   only the operation actually proved.
5. **Display-only schematic transaction, then separate wiring work.** After page
   ownership and persistence are proved, reuse the existing display compilers
   for literal root Text/Attribute fields with unchanged connectivity and peers.
   Keep wire changes separate until complete flat contact/topology semantics
   replace the former compiled exporter, which could annotate and Save All.

an explicitly derived transport plan are prerequisites. The current mixed
fixture would still contain unsupported Components and Pads.
