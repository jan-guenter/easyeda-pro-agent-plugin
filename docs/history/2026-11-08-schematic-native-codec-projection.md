# Schematic native codec projection

The closed schematic build admits only its three original own7 writer, Wire and
saved-reader births. It now retains the immutable shared Via codecs without
compiling the newer Via runtime state, sender methods, action admission and
PowerShell dispatch that those births cannot reach. The diagnostic build keeps
the full original Via implementation. The inverse layout is unchanged.

The six projected source families are local upload, upload request, tail
observation/delete, post-history sync, Save drain and observed source. Each keeps
its exact complete static protocol class source, embedded programs/tables,
lengths, hashes and original scalar/handle validators. Only the required static
JSON quote bridge remains in the owner partial class. A fixed build-only
projection checks the exact class roster, quote method and owned block; unexpected
or edited input refuses. The standalone Via Save-generation runtime fragment is
omitted from schematic, and its shared polling support uses the existing
immutable timer codec-only emitter. No runtime flag, counter, authority check or
public operation chooses these build fragments.

On this source union, the schematic compiler input fell from 2,072,747 to
2,054,191 bytes, recovering 18,556 bytes and leaving 42,961 bytes below the
unchanged 2 MiB ceiling. Stored helper size is 1,491,610 bytes. Diagnostic and
inverse stored helpers remain byte-exact against their pre-change private
outputs, and both retain byte-exact second generation. Schematic generation and
its closed driver also repeat byte-exactly.

Two source regressions pass, comparing every shared static class byte-for-byte
and proving the Via state/senders/dispatch are absent only from schematic. Invalid
class/quote rosters and changed preexisting projection blocks refuse. Initial
assertions used two incorrect source marker/method names; correcting those test
literals required no production change. Both TypeScript configurations and strict
changed-file lint pass. The complete schematic source compiled with Linux .NET
C# language version 5, and all own7/Wire/saved-reader plus eight shared codec
smokes passed. No cap, released role, tracked helper, pin or bundle changed, and
no application or Windows helper was launched.
