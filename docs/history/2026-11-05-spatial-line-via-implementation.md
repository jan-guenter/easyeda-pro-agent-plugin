# Mixed Line and Via spatial reader

This implementation follows main `b16fb1e64c0d4cb0b2f57d2c4f07a894bb80940d`.
It adds the reachable `spatial/observe-spatial-lines` action through the existing
original-owner disposable lifecycle. The Via-only action and released result
schemas remain separate. Both actions consume the same original batch slot.

The SDK's Line corresponds to native Track, not the graphical native Line
model. The new program admits standalone unlocked ready Tracks on copper1/2
alongside through Vias, with complete supported tree membership, reciprocal
model/view, existing model AABBs and view/index octagons. Nondegenerate finite
endpoints and native width at least0.05 avoid the unqualified camera fallback.
The256-object and1024-tree-node limits apply across admitted families/layers.
Other families, pending index maintenance and region border crossings refuse.

Fixed roster encoding reduces the Via program from57,081 to49,279 bytes without
dropping descriptor, parent or function checks. The mixed program is54,414 bytes
before final source freeze; exact final sizes and digests belong in the batch's
release proof. Its escaped command remains below65,536 bytes. Thirty additional
fixed callees bring qualification to256. Limiting the mixed batch to15 queries
gives103 opening/source/reproof requests plus281 spatial requests, exactly384,
including final group release. The existing native ceiling is unchanged.

Private source evidence remains outside the repository. An original-position
Node24.18.0 inspector harness qualified all256 descriptions and locations from
the complete pinned PCB asset, SHA-256
`a84059304d32d4f0feb768d6c5baf00d72a954643ac62299f2c46c08fa68fd0b`.
It ran twelve mixed-scene queries using vendor function bodies in an isolated
Node realm. No application or project was opened. These are offline source-path
results, not embedded-renderer or connected validation.

Focused regressions cover guard ordering, complete mixed selection and hit
order, locked/degenerate/stale/unsupported state, reference changes between
samples, immutable mixed journal schemas, shared-slot consumption, no variant
fallback and fixed native request/command limits. Native CompileOnly smoke also
checks the fifteen-read sequence and rejects switching into the Via program.
Actual Windows compilation and complete suites remain batch-release checks.

The route retains false claims for full native graph/intrinsic qualification,
source membership and persistence. Positive connected validation still needs a
registered Line/Via-only disposable fixture. This work does not enable ordinary
populated-board spatial queries, writing or Save, and does not change the excluded production project.
