# Closed-purpose Via SDK source projection

The new build-only APIs `projectCurrentSchematicViaSdkRuntime` and
`projectCurrentFootprintInverseViaSdkRuntime` replace the unused Via SDK packed
program, encoder, sender and positive codec smoke with fixed throwing compatibility
members. The selected schematic driver admits only original seven-record display
and Wire births. The inverse driver admits only its original inverse birth.
The original Via factory, foreign-purpose refusal smoke, SDK property reader,
shared SQL, worker, actor and static codecs remain present. This commit introduces
no generator hook; each purpose composition must explicitly opt in.

The projection matches the exact original packed program and complete encoder,
smoke and sender bodies, including the four existing sender guards. Its complete
member census refuses duplicate, mixed, changed or partially projected input.
Reapplying the same qualified projection is byte-identical. The inverse wrapper
uses the maintained smoke-vector expand/reproject pair to preserve its existing
bounded storage format while deleting only this unused positive smoke vector.
No compiler, fixed-table or review-source bound changes.
