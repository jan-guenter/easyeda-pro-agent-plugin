The existing layout compiler's complete transaction explicitly requires its
old149 encoder. Its guard remains unchanged. Two exports reuse only the existing

projection declares every difference. The exact original methods in both pinned

`scripts/check-generated-schematic-display-source.ts`; this checks four source
methods and constructs no native model, app or writer capability.

## Native join API

`generated-schematic-display.ts` exports purpose
`schematic-display-write209`, profile `generated-schematic-display209-v1`, strict
prepare/execute/cleanup request schemas and the argument validator.

`generated-schematic-display-source.ts` exports:

- `buildGeneratedSchematicDisplayNativeArguments(prepared, operationId, patch)`
- `requireOriginalGeneratedSchematicDisplayNativeArguments(value, prepared)`

The first argument is the genuine `GeneratedSchematicFixtureOpenCheckpoint`.
The private argument object's canonical bytes and exact checkpoint identity are
retained in a WeakMap. Its operation fields are operationId, textId, beforeBody,
afterBody and five complete peer records: CANVAS, Wire/Bus and their two Lines.
The data still grants no native birth or independent mutation authority.

`generated-schematic-display-program.ts` exports:

- `GENERATED_SCHEMATIC_DISPLAY_FUNCTION`
- `GENERATED_SCHEMATIC_DISPLAY_STAGES` (`capture`, `preflight`, `modify`, `observe`, `save`)
- `GENERATED_SCHEMATIC_DISPLAY_SAVE_SOURCE`
- `generatedSchematicDisplayArgumentsValue(value, genuinePrepared)`

The capture stage returns the original remote holder, retaining the original
SCH/page/source/action/SDK Save receivers. Later stages use that same original
holder. Application-owned getter bindings such as SCH.docMemoryManager and the
shape actionRunner retain their real descriptor/getter identity; standard
browser globals use their normal browser reads. Original window, project,
branch, real parent/page, URL, tab, handler, tree and complete source ownership
are checked throughout. Attempt flags precede awaits. A stopped write or failed
Save cannot replay, and context drift returns an inert partial without a second
application call in the catch path.

Save uses the existing original `_EXTAPI_ROOT_.sch_Document.save` receiver and
its exact installed method. No SDK constructor, new EDA instance, extension ID,
ordinary owner upgrade or arbitrary injected function is accepted. The stage's
Promise acknowledgement proves no backend or structure completion. In
particular Save can republish changes and schedule PROJECT.STRUCTURE even for a
presentation-only patch; the original worker/main fence must prove that work
separately. Every stage keeps structure, persistence, inverse and connectivity
acceptance false.
