# Project history

This directory contains repository research, reviews, work logs, release reports,
validation results and handoffs. These records are evidence, not current agent
instructions or an executable work queue. Historical "current", "next" and
"pending" statements may be superseded. Never replay an edit, Save, navigation,
restart challenge or consumed probe from a record.

## Maintaining records

Use `YYYY-MM-DD-topic.md` for new entries. Add `HHMMSS` after the date when
same-day ordering matters. Retained multi-day records use
`YYYY-MM-DD-through-YYYY-MM-DD-topic.md`; month-only records retain their known
precision. Keep entries scoped and link corrections or completions to earlier
observations. Preserve failures and original limits. Record new results in a
new dated file and add it to the index below.

Keep lasting repository instructions in [AGENTS.md](../../AGENTS.md), reusable
guides in [docs](../README.md), and human setup/usage in the
[README](../../README.md). The [connected-validation protocol](../connected-validation.md)
describes the evidence needed for live test cases. Private evidence, raw designs,
credentials and user project histories stay outside this public repository.
