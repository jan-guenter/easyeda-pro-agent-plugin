## Exact passive observations

event, batch and registered Canvas data. A structural input or receipt grants
no original owner. Every await retains the host's current-custody checks.
Every returned authority, body, cancellation, delivery, publication, worker,
Modify and Save flag is false.

- Before captures the actual ticket formals and fresh onChange caller, joins
  the original caller tuple, derives the same PROJECT/method/native references,
  requalifies native setTimeout arity 1 and clearTimeout arity 0, and requires
  isReady true, publishTimer null and the omitted ticket argument undefined.
- Introduced observes only PROJECT.publishTimer null to a positive native ID,
  distinct from the Canvas timer. The original exact delta brackets a fresh
  snapshot. The pending Canvas Promise and ordered CM collections stay intact.
- Cleared observes the separately owned cancellation effect from that exact
  introduced snapshot and ID. The original registered Canvas baseline must
  again pass the unchanged generic SAME reader. The collector never cancels.
- Websocket entry and return retain the actual false private flag, the same
  PROJECT/methods and a fresh original onChange caller. Remote return joins all
  eighteen original CM frame fields against unchanged descriptors/collections.
- Batch return joins its original two-field caller and admits only the source's
  new own cache-row length 0. Pend remains length 1. Unknown string/Symbol
  descriptors, their order, signed zero, prototypes and peers remain exact.
  The bounded parent-delta recipe brackets the new complete snapshot.
- Handler return joins the original event frame and uses the retained native
  event getter references with eventRead/eventSame. It does not reuse the older
  two-field cache-row recipe after the source adds length. The updated complete

- Timer entry captures the canonical three-field Canvas frame and joins the
  same Sheet, resolver, created Promise and native prototype. Promise metadata
  must remain pending with an undefined result and zero own properties. The
  timer body and resolving function remain uninvoked.
