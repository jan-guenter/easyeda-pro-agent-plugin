# Original schematic run-prefix collector

The source continuation after `500c4812` adds a finite readonly cursor for the
still-held original seven-record schematic run. The enclosing owner must keep
the actual original invocation, completed raw scene, idle tuple, source variant
and correlated Inspector requests. A copied cursor or parsed handle supplies
no owner or continuation authority.

The collector qualifies the complete pinned renderer source, actual run and
module tuples, queue subscriptions, WillEnd disposal, manager/channel links,
single-shape weak references, 34 source callees and 17 original queue callees.
It reads each new object's native metadata before following its descriptors or
prototype. A fixed JavaScript identity comparison handles multiple Inspector
wrappers of the same object. Twelve prototype levels, 384 unique objects and
4,096 requests are refusal bounds, not permission to search an arbitrary graph.

Native qualification includes 34 methods and constructor/species getters,
Array/Set/Map iteration aliases, the actual Map iterator and the source
generator's iterator chain. Creating the private Map iterator neither advances
an application iterator nor calls the application generator. Queue and raw
descriptor guards are reproved before the collector completes. Historical
result schemas and older general native-method parsers remain unchanged.

Three focused checks passed on Node 24.18.0. They exercise fixed-program
substitution refusals, actual Inspector native-function and nullable-root
packets, Proxy refusal without traps, and the Map iterator program with the
production `throwOnSideEffect: true` setting. Strict type-aware lint and both
TypeScript configurations passed for this slice. These are inert local checks.
They establish no original owner, live action, Save or reopened result.

The grammar also defines three fixed callback-entry guards. The readonly cursor
never emits an arm, remove, resume, setter or Save command. Original-owner
transport and native admission, function-entry receiver checks, callback handoff,
Modify settlement and saved/reopened validation are separate pending work.
