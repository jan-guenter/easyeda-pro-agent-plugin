  debugger columns do not. No blanket offset substitution is used.

  compiled generation-specific breakpoint branch. Its immutable launch purpose

  The original shared256-command counter is retained across handoff.
- The [common-baseline implementation](2026-10-24-generation209-common-baseline.md)
  maps30 semantic class roles to exact209 lexical bindings, captures retained
  scope data, and joins its own original replies to the original SQL inventory.
  It is an empty-target subset with a3090-command maximum, plus parent checks.
  It is not exposed through the256-command startup owner.
- The [actor/clock source adapters](2026-10-24-generation209-actor-clock-source.md)
  qualify five exact assets, including the websocket time responder. The startup
  route uses the four-sample adapter. The six-sample PCB adapter and fixed
  server-time request generator remain private. Source qualification is not
  live responder ownership or native clock provenance.
- A separate private209 PCB-session continuation preserves original opening,
  context and checkpoint objects. It is not registered. The current transport
  rejects an unexpected new PCB/ratline worker; this batch does not suppress
  that worker or claim completion of its work.
