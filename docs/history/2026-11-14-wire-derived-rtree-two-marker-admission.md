## Concrete implementation

The new current-schematic-wire-derived-rtree family qualifies both complete
installed schematic source variants before comparing thirteen original complete
spans (14,930 bytes per variant): the RBush factory; model-index, point-range,
connection-node and point classes; the group rTree exclusion; line geometry and
base bbox methods; and net-point rebuild/analyze/refresh methods. Class metadata
retain the original non-writable own prototype property. Exact source text,
name, arity, original script/PC, parent description and own descriptors are
compared. The later point ORIGIN assignment is treated separately; matching
class metadata does not prove original closure/static bindings.

The production cursor performs a fixed descriptor census of the known fixture.
Its generated final comparison rechecks every traversed application object
against the exact Inspector-qualified reference table before descriptor,
prototype or collection access. It compares the five-node model index and its
flat RBush root, the four-node point-range tree at range 0.25, exact model/node
and Map/child membership, native collections, root unions, LINE bounds, marker
replacement and connection memberships. It retains original TEXT/BUSLINE index
nodes, bbox objects, prototypes, scalar bounds and source-created data
descriptors. Original containers, page, module, selected models and project
metadata remain joined to the same holder. The old marker IDs cannot reappear.
This reader admits only that exact observed index roster; a different visible
model or unsupported layout refuses.

The before packet is an opaque, locally issued single-successor object. A
copied packet, reused successor, failed reservation or malformed reply cannot
create a new read attempt. Source comparisons and supplied observations issue
no original event, callback, bbox, publication, mutation or Save grant.

A separate unmounted generated stage program adds the explicit two-marker
admission check before context discovery, point construction or Modify
dispatch. Axis-aligned after endpoints must be separated by more than 0.25.
The original parser, generated stage bytes, v4 purpose and all unsupported
branch guards remain unchanged. The successor uses a separate result schema.
The old parser alone continues to admit short geometry; it is not the intended
full-writer entry.

## Finite reservation

Before uses 94 metadata reads plus one Map extraction, one fixed 112-slot
reference table and one final comparison: 97 requests. After adds five metadata
reads (new scene, old marker array, two old marker models and the original
private snapshot): 102 requests. Six actual generated calls have separate
helper-source obligations. With one original object-group cleanup the component
reservation is 97 + 102 + 6 + 1 = 206. The table's unused slots repeat the
already retained native table and cause no additional application reads.
Original class/function source qualification, breakpoint/event custody,
resumes and the rest of the complete writer remain separate obligations.

## Validation and limits

Eleven focused tests pass with zero skips against both configured whole
installed source variants. Actual Node Inspector class metadata comparisons
cover all thirteen functions/classes at their original source PCs. The
structural fixture executes the original RBush factory, model and point-range
classes, original point/connection constructors, and original net-point
rebuild/analyze/refresh methods. Model/marker ownership, rendered bbox inputs,
event delivery and publications are explicitly inert stand-ins. Both variants
consume exactly 97 before and 102 after requests.

Negative cases refuse a same-byte substituted peer, merged endpoints, stale
LINE bounds, a non-leaf root, copied/consumed successors, open command syntax,
copied reservations and malformed replies. A bbox replaced after metadata
qualification is refused with zero Proxy descriptor/prototype/key traps.
The admission regression refuses 0.01 and 0.25 separation before constructor or
dispatch code and distinguishes the supported 0.2501 and 100 branch.

Pinned Linux Node 24.18.0/npm 11.16.0 with soft core limit zero, both TypeScript
checks, strict type-aware lint of the eleven changed TypeScript files, and the
repository/MCP/all-skill validators pass for the sealed leaf. Bundles
and native generated artifacts remain the root integrator's responsibility.

This is component source/Inspector evidence. The complete writer factory,
three original WIRE/LINE/ATTR worker publications, complete AST completion,
original action-end caught-error guard, Main/SQL Save and the separate cold
saved reader are not established by these comparisons. No live Wire mutation
or saved/reopened result is claimed.
