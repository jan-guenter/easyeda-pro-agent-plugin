stage. It retains one original Promise and admits one version plus at most
eight actual inventories on this same original native generation. Only empty
inventories may precede page birth. Once the first page appears, its target ID
stays pinned through empty/about:blank URL to the exact unattached Start Page.
Closure, replacement, extra pages, foreign URLs or foreign attachment refuse.

actual UI source/runtime context. The 250 ms pauses only schedule another
observation; eight empty inventories produce a refusal. There is no navigation,
replacement owner, resume or elapsed-time completion inference. Other purposes
retain the original single-sample `browserObservation()` contract.

owned PowerShell block preserves the prior saved block byte-for-byte during
