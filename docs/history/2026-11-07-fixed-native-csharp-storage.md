# Fixed combined C# compiler-input storage

The combined helper exceeded its unchanged 2,097,152-byte at-rest ceiling after the original Via drain, inverse cold-load and fixed source lanes were composed. Six identical native Quote bodies offer at most about 3.3 KB before excluding released graphs; this cannot provide the requested 15 KB of usable headroom. Existing program tables already pack the inverse and drain declarations together.

The new final-emission transform stores only the combined helper's one fixed C# body as gzip/base64. Every marker-based generator first restores the exact literal body. Forward and cold-forward migration restore it before their existing full source admission/projection. Neither released three-role graph is re-encoded or changed. The at-rest helper and decoded C# each retain the existing 2 MiB bound; there is no raised limit or caller-selected decoder input.

Production restoration verifies exact embedded compressed length/SHA-256 and canonical base64 before constructing the gzip stream. The fixed gzip envelope, decoded length, extra-read/input-end checks, decoded SHA-256, ASCII/no-BOM and strict UTF-8 checks precede Add-Type. Build restoration also compares canonical pinned gzip bytes, rejecting extra empty members and ignored padding. The synthetic launch smoke reader uses the same fixed decoder before its original in-memory hooks. All other native marker generators expand first and retain the original storage form. Forty-two source-inspection test readers explicitly expand before their unchanged C# assertions/mutations; mixed readers retain original stored bytes for file size/hash/ASCII checks, and generated-file bounds are checked after packing. Original NativeCompileOnly dispatch remains after compilation.

All replacement storage measurements use **Node 24.18.0 and a zero core limit**. On the checked source union (canonical `ecb590f7` plus inverse cold-load `b9fdd01a`), the expanded helper was 2,113,069 bytes and its C# body was 1,905,134 bytes, SHA-256 `283d7cc8194733b35ac3345745e1dc2a736b09a305e58c900c0d2b94173066cf`. Final stored helper size was **1,383,728 bytes**, leaving 713,424 bytes below the unchanged at-rest limit. Two complete generation passes were identical. Earlier reported 2,094,847 / 2,101,777 / 2,109,973-byte storage observations used ambient Node 26 gzip and are superseded; they are not pinned reproducibility evidence. Their full debugger message bytes were independently retained, and are unchanged by this transform.

Focused roundtrip and hostile-storage regressions cover changed hashes/lengths, malformed/noncanonical base64, duplicate/unknown storage, mixed literal/packed bodies, corrupted gzip, ignored tails, extra members, oversized decoded source, non-ASCII/BOM/invalid UTF-8 and changed decoder text. All six released forward/cold files are compared byte for byte. The earlier independent 13-program expanded Via/SCH/replay parity checks remain intact. Both TypeScript projects and changed-file strict type-aware lint passed.

The entire restored C# compiled under Linux. Nine static protocol smokes passed, including all new 63/68/1 Via message hashes, full Via/SCH worker encoders and initial cache/sync/periodic/producer encoders.
