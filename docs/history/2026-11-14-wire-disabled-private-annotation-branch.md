## Original branch and actual captured value

The original schematic annotation factory u0e/Ede first returns null when its captured No/Bo flag is false. That flag comes from IS_PRIVATE, derived from whether PRO_EDITOR_MODE contains PRIVATE. Only the enabled branch reads globalThis.annotationPanel and can construct the annotation manager.

Original ja/openCanvas and its second-variant equivalent assign annotationManager through this.annotationManager || this.register(factory(this)). The original disposable register method returns its input, including null. A canvas opened with the disabled factory therefore stores a null annotationManager and creates no annotation manager through that factory.

The reader does not assume the installed runtime's mode. It qualifies the whole schematic bundle and three complete original spans per variant: openCanvas, the factory and register. It finds the actual inherited openCanvas through at most twelve original ordinary prototypes, qualifies its actual function/script/PC metadata and selects the original factory from its real scope list. It then qualifies the factory's complete metadata and reads its own captured No/Bo and original factory binding from that factory's scope list. Each scope list is bounded by eight.

The captured flag must be the boolean false. The original page's own annotationManager descriptor must contain exactly null, its original canvas must be present, and the same holder/state/before/page/models/shapes/host/metadata/canvas references must survive the final comparison. No getter, original factory, register, canvas method or annotation callback is invoked by this reader. Its helpers only inspect fixed own descriptors and compare references.

## Scope of the absence comparison

A null manager alone is insufficient. The flag and actual factory binding must also be compared, and the complete original observer rosters remain separate. The returned data therefore keeps observerRosterComplete, annotationLifecycleComplete, originalHeldEventJoined, mutationAuthorized and saveAuthorized false. It establishes no original opening, complete annotation absence, mutation or Save ownership.

If the actual runtime has private mode enabled or an annotation manager exists, this branch refuses. The enabled observer's debounced notification still needs its original RPC argument, actual returned Promise, exact callback result pointer, normal callback return and cleared original Set. Its native MessageBus default timeout returns a Promise.race, so the local base Promise is insufficient. Existing immutable UI return-site data can support that separate Wire origin, without reusing a footprint issuer or registry.

The previously researched 1,600 ms notification behavior applies when an annotation observer was actually created. It is not a reason to fabricate an observer for a disabled original factory.
