# Bounded geometry schema discovery

The frozen development package's offline probe refused a bulk geometry schema
reply of621381 bytes. The512KiB response guard remained intact. Each of the22
entries had repeated the entire argument union, even when the caller selected
one exact method. Discovery now publishes that method's exact argument branch
with a literal method discriminator. Live request parsing and observation
permissions are unchanged.

The focused existing discovery regression now checks the real offline envelope
against512KiB and verifies every argument schema's method discriminator and
closed field roster. It passes, as do both TypeScript projects and strict
changed-file lint. The offline probe's stale20-method expectation is corrected
to22, and failures identify their action. The original fixed79-query budget
is preserved. The operating reference explains exact method selection.

The first private copy was probed before materialization had fully completed.
That run failed, and a second run after complete materialization failed too;
copy timing did not establish the cause. A separate private diagnostic captured
the actual bounded API error. Temporary per-method probe attempts then exposed
the stale count and a wrong expectation that the old input schema was already
an object rather than the complete union. Those failures are retained. The
final change fixes the discovery producer and retains the complete bulk probe.

No frozen package was modified, installed or selected after those failures.
Original synthetic probe children closed through EOF without signals; no live
control root, upstream service or EasyEDA application was selected. A new
frozen payload and its complete offline proof are pending.
