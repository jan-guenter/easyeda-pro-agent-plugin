token-fusion format. The original v1/v2 decoders, successful output and default
v2 packing stay unchanged. The generator expands the fixed selected-Main program
storage before normalizing source markers, and applies its lossless projection
only to inverse/schematic after installation derivation. Diagnostic and separate
saved-reader helpers remain byte-identical to the clean `d24624d6` base. No
compiler, review, spacing, table, request or runtime purpose limit changes.

selection. Exact throw-before-pack measurements showed schematic v2/v3 compiler
