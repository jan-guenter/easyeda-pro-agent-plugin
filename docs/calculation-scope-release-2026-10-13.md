# Calculation-scoped backlog release

Candidate `0.3.0+codex.20261013135500` continues the backlog after PR10. It adds
eleven methods without admitting the newer editor for design work.

## Delivered scope

- `easyeda_control_calculate` calls eleven fixed `eda.sys_Math` methods with
  strict coordinate, geometry and output bounds. It accepts no code, native
  objects, project selection or callbacks.
- Offline `calculations` and `calculate-validate` expose exact schemas and
  non-authorizing argument checks. The inventory now has 204 public subsets,
  30 native equivalents, 82 implemented-but-blocked methods and 458 omissions
  across 774 distinct paths. Those are implementation counts, not live proofs.
- New or unknown configured generations register only API reference, local
  discovery, status and calculations. Each execution still requires the exact
  separate app/API/PCB fingerprint and authenticated session. Missing selected
  installation files retain the preceding three-tool offline-only entrypoint.
- An explicit checkout profile-upgrade command verifies the installed new
  generation, preserves an exact private backup and changes only two version
  selectors. It does not change old compatibility pins or take over an owner.
- Control and extension skills describe this boundary, exact argument discovery
  and geometry limitations. Seven skills remain packaged.

The [method review](sys-math-implementation-review-2026-10-13.md) records all
eleven contracts and the five clipping omissions. The
[compatibility review](easyeda-3.2.206-compatibility-review-2026-10-13.md) records
the separately reviewed connection/calculation closure and migration.
