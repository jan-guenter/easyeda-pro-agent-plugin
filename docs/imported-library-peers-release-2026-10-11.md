## What changed

Imported ordinary SYMBOL/FOOTPRINT atom history can now retain its `firstTicket`
provenance instead of being discarded or incorrectly treated as display order.
Default parsing stays strict. The maintained opt-in binds every occurrence,
including tombstones and raw encodings, to the immutable checkpoint.

Existing-project opening and the flat diagnostic retain and verify those
commitments. A separate sealed flat-display v2 profile permits the same existing
attribute/text display edits as v1 while requiring all imported peers to stay
unchanged through apply, inverse, Save/reopen and recovery. It does not enable
placement, electrical edits, library writes or generic compiled topology.
See [the parser and consumer contract](native-library-import-history-2026-10-11.md).

Independent reviews found and corrected malformed-summary admission, a legacy
restoration regression and mutable recovery input across an await. Regression
tests exercise these cases, serialized/cloned proof refusal, provenance drift
with equal semantic hashes, interrupted apply and retained-Save reconciliation.
