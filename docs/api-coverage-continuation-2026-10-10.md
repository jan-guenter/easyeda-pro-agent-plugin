## Implemented changes

- `library.symbol.modify`: ordinary closed project-local symbols, exact name
  and non-null description only. A complete bounded tab tree must contain the
  expected active document and no empty leaf or target tab. The public method's
  classification/default-title defects are handled explicitly. Full-project
  effects, retained preparation/return receipts, no-redispatch reconciliation
  and an independently verified inverse-operation builder are implemented.
- `document.activate`: one already-open checkpoint-member tab, complete owned
  tab inventory, loaded-frame identity, retained preparation and one activation.
  PCB/footprint targets require an existing preference value that avoids a native
  account-preference write; the adapter never sets that preference. Context, complete
  project history and logical database invariance are verified. Recovery never
  repeats activation, opens a document, closes a tab or saves.
- `schematic-flat-topology`: separate diagnostic reader. Checkpoint and public
  declarations bind every page; all pages and templates must be initialized.
  Two synchronous native/source/contact captures must agree. The initial domain
  is single-part components and explicit named orthogonal wires, at most sixteen
  loaded pages and a 4 MiB escaped response. Unsupported electrical structures
  refuse. The old compiled-topology reader and its transactions remain blocked.
- Minimized-window discovery uses finite Win32 bounds when UI Automation returns
  an empty/infinite rectangle. No usable bounds yields null, not invalid JSON.
  Skill guidance requires restore/reinspection before deriving input coordinates.
- Repeated journal scans retain bounded validation descriptors and small cloned
  projections. Every use still verifies complete fresh journal and artifact
  bytes and managed paths. A read-only 263-journal benchmark measured 40.008 s
  cold versus 13.157 s repeated; this is not a promised end-to-end call latency.
