## Changes

- `sch.wire.modify` gains the separate facade-owned
  `flat-wire-reroute.v1` profile. It changes integer endpoints of nonzero
  orthogonal segments in one existing unlocked named WIRE. Every LINE ID,
  count and style, every ATTR field and category-derived child order remain
  unchanged. Complete flat topology and a contact-incidence multiset preserve
  pin and foreign-wire contacts, including their coordinates. Generated-marker
  ownership and reciprocal indexes are checked; shared-WIRE endpoints and
  pin-bearing junctions refuse. The exact ID-to-segment inverse requires a
  fresh unchanged durable baseline. Auto-persisted forward effects refuse
  unsaved rollback. One-shot Save/reopen and original retained-Save recovery
  preserve full peer proof. No compiler, annotation, Save All, creation,
  deletion or style/net change is admitted. Generic compiled wire transactions
  remain blocked, and historical journals are not migrated to this profile.
- The explicit-ID PCB readers provide native-source DTOs for one exact ID or
  1–256 unique IDs in caller order. Supported root families are Line, Arc, Via,
  standalone Pad, Component and STRING, with direct source-backed ATTR records.
  Complete owning-family correspondence and two source/inventory/source cycles
  are required. Missing, inherited, generated, unsupported or colliding requested
  IDs refuse the entire call. These readers do not sample selection, return
  public class instances, silently drop IDs or claim public-wrapper parity.
- Selected-object guard coalescing removes ten redundant outer boundaries while
  retaining both observation cycles and every constituent double sample.
  Passive stage timings contain fixed bounded labels, counts and durations
  outside compared observations and semantic hashes. Failures retain diagnostic
  evidence without replacing the original exception or result. No connected
  latency improvement has been measured for these changes.
- Passive navigation admission rejects a known unsafe `pcbCommandTab` state
  without changing settings. Execute checks before applying an edit that promises
  Save/reopen; commit checks before consuming Save intent. Generated Save,
  close, open and activation dispatches repeat the appropriate guard after
  awaited context checks. Project opening remains guarded because it can restore
  PCB peers even for a schematic target. A complete schematic/symbol-only tab
  registry can establish the narrower close exemption. Inactive clean close
  additionally requires the sole container and global active-tab identities,
  and their complete ordered tab objects, to agree.
